SOURCE CODE
Packages installed via apt come from the Debian and Raspberry Pi OS
archives; their exact corresponding source is available from
https://deb.debian.org and https://archive.raspberrypi.com (or run
`apt source <package>` on this device). Software built from source by the
RF Pi installer is fetched from the upstream URLs above; build recipes
are in the installer itself. If you would like any of this source on
physical media, contact the address in /etc/hampi/vendor.conf and it
will be provided at cost, per the GPL.

Map coastline data: Natural Earth (public domain, naturalearthdata.com).
Solar-terrestrial data feed: N0NBH (hamqsl.com). Weather: Open-Meteo.

The RF Pi suite is proud to stand on this work, and none of it is being
sold to you.
